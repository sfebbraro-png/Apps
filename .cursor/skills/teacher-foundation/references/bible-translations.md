# Bible translations guide

Default for this collection: **ESV** (English Standard Version).

Use the translation set in `BIBLE_TRANSLATION`. When comparing versions (e.g., in lesson-research word studies), note meaningful differences without treating any single translation as inspired over another.

## Common translations

| Translation | Abbrev. | Character | Good for |
| --- | --- | --- | --- |
| English Standard Version | ESV | Essentially literal; readable formal equivalence | Default teaching, public reading, study notes |
| New International Version | NIV | Balanced dynamic/formal; very common in churches | Group members likely using NIV |
| New American Standard Bible | NASB | Very literal; formal | Precise wording comparisons |
| King James Version | KJV | Historic; archaic vocabulary | Tradition, poetry, older members |
| New Living Translation | NLT | Dynamic equivalence; very readable | Clarity for new believers, narrative |
| Christian Standard Bible | CSB | Optimal equivalence; readable | Growing evangelical use |
| New Revised Standard Version | NRSV | Mainline scholarly default | Academic or ecumenical contexts |

## Usage rules

1. **Quote from one translation** in exposition and teaching outputs (`BIBLE_TRANSLATION` unless user switches).
2. **Cite precisely:** book, chapter, verse. For ranges, use en dash in references (Romans 8:1–11) in prose; follow user preference if they avoid dashes in body text.
3. **Label paraphrases.** If summarizing rather than quoting, say so. Never present paraphrase as quotation.
4. **Comparison columns** (research skill): note when NIV, ESV, KJV, NLT, NASB diverge and why it matters for interpretation.
5. **Do not proof-text** across translations to force a meaning the original language does not support.

## Reformed tradition note

Reformed teachers often prefer essentially literal translations (ESV, NASB, CSB) for study and preaching. NIV and NLT are valuable for accessibility in mixed groups. Acknowledge when your group's pew Bibles differ from your teaching translation.
