# Proofreading checklist

Use this reference before writing the report. An item is a fix candidate only when it falls within proofreading scope (see SKILL.md). When a finding shades into voice, argument, or substance, put it under Notes instead of inventing a rewrite.

## Spelling and word usage

- [ ] Misspellings and typos
- [ ] Homophones and near-homophones (their/there/they're, its/it's, your/you're, affect/effect, lead/led, loose/lose, than/then, accept/except, principle/principal)
- [ ] Wrong word for context (comprise/compose, fewer/less, imply/infer, who/whom where agreement matters)
- [ ] Proper nouns, names, and transliterations spelled the same way throughout
- [ ] Hyphenation of compound modifiers by position (e.g. well-known author vs the author is well known)
- [ ] Accidental doubled words ("the the", "to to")
- [ ] Missing or extra letters that still leave a real word (form/from, quiet/quite)

## Grammar

- [ ] Subject-verb agreement, including collective nouns and inverted order
- [ ] Pronoun-antecedent agreement and clear antecedents
- [ ] Verb tense consistency within a section or narrative stretch
- [ ] Parallel structure in lists and correlative constructions (both/and, either/or, not only/but also)
- [ ] Article usage (a/an before vowel sounds; missing or extra articles)
- [ ] Modifier placement (dangling or misplaced modifiers)
- [ ] Comparatives and superlatives formed correctly
- [ ] Sentence fragments — fix only when clearly accidental, not intentional rhetorical fragments

## Punctuation

- [ ] Comma splices and run-on sentences
- [ ] Missing commas after introductory clauses or phrases where needed for clarity
- [ ] Serial (Oxford) comma used consistently with the document's established style
- [ ] Apostrophes in possessives and contractions (its vs it's; plural possessives)
- [ ] Quotation marks and adjacent punctuation consistent with the document's style (American vs British)
- [ ] Colons and semicolons used correctly (independent clause before a colon that introduces a list or elaboration)
- [ ] Em dashes, en dashes, and hyphens used correctly and consistently
- [ ] Parentheses and brackets balanced; punctuation placement consistent with house style

## Capitalization and numbers

- [ ] Sentence-initial capitalization
- [ ] Proper nouns, titles, and headings capitalized consistently
- [ ] Specialized terms (book titles, product names, Scripture references) formatted consistently when the piece uses them
- [ ] Numbers: spell-out vs numerals consistent with the document's style
- [ ] Percentages, dates, and times formatted consistently

## Consistency

- [ ] British vs American spelling (colour/color, favour/favor, towards/toward) — one system throughout
- [ ] Terminology for the same concept (don't switch synonyms without a reason the reader can follow)
- [ ] Heading hierarchy and formatting
- [ ] List style (bullets vs numbers; end punctuation on list items)
- [ ] Italics vs quotes for words-as-words, titles, and foreign terms
- [ ] Formatting artifacts (escaped markdown like `\*word\*` that should be real italics; broken links; stray HTML)
- [ ] Section headers present and styled consistently if the piece uses them

## Paragraph construction

- [ ] Each paragraph develops one main idea (unity)
- [ ] Mid-paragraph pivots noted with a precise split point (quote the sentence before/after)
- [ ] Length judged against the piece's own pacing, not an absolute ideal
- [ ] Opening sentence signals the paragraph's topic, or the delay is flagged
- [ ] Transition from the previous paragraph and into the next is clear enough, or abruptness is flagged
- [ ] Orphaned one-sentence paragraphs merged only when they don't read as intentional punch

## Final pass

- [ ] Read for awkward breaks the eye might miss even when each sentence is locally fine
- [ ] Check first and last paragraphs of each section against the rest of the piece
- [ ] If citations or quotations appear, flag obvious mismatches (without doing a full fact-check)
- [ ] Confirm every numbered report item is either an in-scope fix or a Notes flag — nothing that silently rewrites voice or argument
