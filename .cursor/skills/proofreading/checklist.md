# Proofreading checklist

Use this reference when evaluating a document. An item is a fix candidate only if it falls within proofreading scope (see SKILL.md). When in doubt, flag rather than rewrite.

## Spelling and word usage

- [ ] Misspellings and typos
- [ ] Homophones and near-homophones (their/there/they're, its/it's, affect/effect, lead/led, loose/lose, than/then)
- [ ] Wrong word for context (literally/literally misused, comprise/compose, fewer/less, who/whom where it matters)
- [ ] Proper nouns, biblical names, and transliterations spelled consistently throughout
- [ ] Hyphenation of compound modifiers (e.g., upside-down vs upside down by position)
- [ ] Accidental doubled words ("the the")

## Grammar

- [ ] Subject-verb agreement (including with collective nouns and inverted order)
- [ ] Pronoun-antecedent agreement and clear antecedents
- [ ] Verb tense consistency within sections
- [ ] Parallel structure in lists and correlative constructions (both/and, either/or, not only/but also)
- [ ] Article usage (a/an, missing or extra articles)
- [ ] Modifier placement (dangling or misplaced modifiers)
- [ ] Comparatives and superlatives formed correctly
- [ ] Sentence fragments — only fix when clearly accidental, not intentional rhetorical fragments

## Punctuation

- [ ] Comma splices and run-on sentences
- [ ] Missing commas after introductory elements where needed
- [ ] Serial (Oxford) comma used consistently with the document's established style
- [ ] Apostrophes in possessives and contractions
- [ ] Quotation marks and punctuation placement consistent with the document's style (American vs British)
- [ ] Colons and semicolons used correctly (especially after an independent clause before a list)
- [ ] Em dashes, en dashes, and hyphens used correctly and consistently
- [ ] Parentheses balanced; punctuation outside/inside consistent with house style

## Capitalization and numbers

- [ ] Sentence-initial capitalization
- [ ] Proper nouns, titles, and headings capitalized consistently
- [ ] Bible book names and Scripture references formatted consistently
- [ ] Numbers: spell out vs numerals consistent with document style
- [ ] Percentages, dates, times formatted consistently

## Consistency

- [ ] British vs American spelling (colour/color, backwards/backward, etc.) — pick one and stick to it
- [ ] Terminology for the same concept (don't switch synonyms without reason)
- [ ] Heading hierarchy and formatting
- [ ] List style (bullets vs numbers, punctuation at line ends)
- [ ] Italics vs quotes for words-as-words, book titles, foreign terms
- [ ] Formatting artifacts (escaped markdown like `\*word\*` that should be real italics)
- [ ] Section headers present and styled consistently if the piece uses them

## Paragraph construction

- [ ] Each paragraph develops one main idea
- [ ] No mid-paragraph pivots that warrant a split (note location if so)
- [ ] Length appropriate to the piece's pacing (not inherently long or short)
- [ ] Opening sentence signals the paragraph's topic
- [ ] Transition from previous paragraph and into the next is clear
- [ ] No orphaned single-sentence paragraphs that belong merged with neighbors (unless intentional punch)

## Final pass

- [ ] Read aloud mentally for awkward breaks the eye might miss
- [ ] Check first and last paragraphs of each section for consistency with the rest
- [ ] Verify quoted material matches source wording if citations are present
- [ ] Confirm nothing in the report crosses into voice/argument rewriting
