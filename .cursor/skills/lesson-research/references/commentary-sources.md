# Commentary sources

This skill draws on the commentators and resources below. **Name the sources you use. Summarize positions accurately. Do not fabricate direct quotes or page numbers.**

When web or library access is available, prefer checking primary sources. When it is not, draw on well-established scholarly consensus and clearly label summary as paraphrase, not quotation.

## Primary tiers

### Expositional (teaching-oriented)

| Source | Best for | Notes |
| --- | --- | --- |
| **Matthew Henry** | Whole-Bible devotional-expository summary | Rich application; less technical on original languages. Public domain. |
| **John Calvin** (*Commentaries*) | Reformed expository reading | Strong on theology and authorial intent. Public domain. |
| **Charles Spurgeon** (*Treasury of David* for Psalms; sermons elsewhere) | Pastoral warmth, Christ-centered application | Not verse-by-verse for every book. |
| **NIV Application Commentary (NIVAC)** | Bridge from exegesis to application | One volume per book; good for group context. |
| **Bible Teaching Commentary / Teaching the Text** (where available) | Classroom and small-group teaching moves | Practical without replacing your voice. |

### Technical / academic

| Source | Best for | Notes |
| --- | --- | --- |
| **NICNT / NICOT** (New International Commentary) | Balanced evangelical scholarship | Strong default for NT/OT exegesis. |
| **Pillar New Testament Commentary** | Readable academic exegesis | Good on discourse and structure. |
| **Word Biblical Commentary (WBC)** | Detailed technical notes | Use for hard passages; don't dump on a group. |
| **Baker Exegetical Commentary on the NT** | Greek-aware exposition | Helpful on grammar and argument flow. |
| **Tyndale / IVP NT Commentary** | Mid-level exegesis | Accessible technical middle ground. |

### Original language tools (for word studies, not quotation)

| Tool | Use |
| --- | --- |
| **BDAG** (Greek lexicon) | Semantic range for NT Greek |
| **HALOT** (Hebrew lexicon) | Semantic range for OT Hebrew |
| **Strong's / Mounce** | Quick orientation only; not sufficient alone |
| **STEP Bible / Blue Letter Bible** (if accessible) | Cross-version and lemma lookup |

### Study Bibles (orientation, not commentary replacement)

| Resource | Use |
| --- | --- |
| **ESV Study Bible** | Introductory essays, maps, concise notes |
| **NIV Study Bible** | Similar; compare note differences |
| **Reformation Study Bible** | Reformed theological framing |

## How to use this list in output

1. **Name 3-5 sources** actually consulted or reliably summarized for the passage.
2. **Separate agreement from divergence.** Widespread agreement is worth stating; friction often marks real textual tension.
3. **Distinguish technical from pastoral.** Note when a technical commentator raises a issue the expositor then applies.
4. **Never invent** a quote, footnote, or "Calvin says on page X."
5. If uncertain on a contested point, say: *scholars disagree* and name the main options.

## Access notes

- Public-domain works (Henry, Calvin, many older sets) are widely available online.
- Modern series (NICNT, NIVAC, Pillar) may require print or subscription (Logos, Olive Tree, library).
- If the agent cannot verify a specific claim, say so and offer the interpretive options without false precision.
